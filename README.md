# Monster Burguer

Site independente feito com HTML, CSS e JavaScript puro (sem React).

## Abrir localmente

Abra `index.html` no navegador. Para testar o envio por WhatsApp, edite `app.js` e informe `WHATSAPP_NUMBER` com o DDI, DDD e telefone somente em números (exemplo: `5585999999999`).

## Ajustar o cardápio

Os itens, categorias, descrições, preços e imagens de demonstração ficam no array `products` em `app.js`.

## Situação desta versão

Esta é a primeira versão visual/interativa: busca, filtros, sacola e formulário do pedido funcionam no navegador. O envio para WhatsApp depende do telefone real do restaurante. Ainda não inclui banco de dados, autenticação administrativa ou painel de pedidos compartilhado entre dispositivos; esses recursos precisam de um backend antes de operar como loja real.

As fotos atuais são imagens remotas de demonstração. Substitua-as por fotos autorizadas do restaurante antes de publicar a versão comercial.
